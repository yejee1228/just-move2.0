> 기준: 수정 전 화면(`357e0d7`)의 디자인을 그대로 이어받는다. 새로 생기는 화면(영상 재생, 농장, 재시작 환영, 로그인 등)도 같은 규칙으로 만든다.

## 1. 디자인 원칙

1. **수정 전 화면과 같은 느낌**: 밝은 회색 배경 위 흰 카드, 네이비 주색, 오렌지 강조. 카드·버튼 모양과 크기를 그대로 쓴다.
2. **가장 중요한 행동은 오렌지 한 개**: 한 화면에 오렌지 큰 버튼은 하나만 둔다 (지금 움직이기, 다음 등).
3. **실패처럼 보이는 색을 쓰지 않는다**: 빨강(destructive)은 삭제·탈퇴 확인에만 쓴다. 쉰 날, 1분 미만, 그만하기에는 쓰지 않는다. 〔R01-08〕
4. **눌렀다는 느낌**: 누르면 살짝 작아지거나(0.95~0.97) 흐려지고(0.85), 중요한 동작에는 진동을 준다.

## 7. 화면별 레이아웃

### H-01 홈 〔D-19〕

**원칙**: 홈에는 할 일 하나만 둔다 — 지금 자세를 눌러 바로 움직이기. 농장·기록·예약은 각 탭에서 본다. 수정 전 움직이기 카드와 같은 구성에, 네이비 대신 **밝은 배경**을 써서 답답하지 않게 한다.

1. **머리 줄**: 왼쪽 로고 24/800 + 문구 "생각은 그만, 일단 움직여요." 12 / 오른쪽 **알림 버튼**(알약 모양, 높이 40, 테두리 1): 켜짐이면 `notifications`(accent) + "14시 알림" / "내일 9시 알림", 꺼짐이면 `notifications-off-outline` + "알림 꺼짐"(`secondary` 배경). 누르면 P-02 알림 설정
2. **움직이기 카드**(흰 `card`, 테두리 1 `border`, 둥근 16, 여백 20, 간격 12)
   - 오늘의 한마디: `primary` 20/800

### M-01 운동 영상 바둑판 (별도 화면) 〔D-20〕
흐름 화면 머리([‹] + 가운데 "운동 영상") → 부제 "영상을 누르면 바로 시작해요. 체크하면 고른 순서대로 최대 10개를 이어서 볼 수 있어요." 14 → 자세 필터 버튼 줄(전체/누워서/앉아서/서서/걸으며, 화면 끝까지 옆으로 밀림, 아래 16) → 바둑판 영상 카드 2열(§6-4). 영상이 없으면 "이 자세의 영상을 준비 중이에요."
- 카드 순서는 맞춤 추천 순서(끝까지 본·자주 고른 영상 위, 중간에 넘긴 영상 아래)

### M-03 운동 영상
수정 전 영상 화면 구성 유지:
1. 네이비 머리: [‹] + 가운데 동작 이름(흰 16/700) + 오른쪽 "n/이어 볼 영상 수"
2. 검은 영상 영역: 남은 높이를 채움. 세로 영상은 높이에 맞추고 가로 영상은 너비에 맞춤. 누르면 일시정지(가운데 `play-circle` 72 + "탭해서 이어서 하기")
3. 영상 진행 막대(4)
4. 정보 영역(`background`, 여백 20, 간격 12):
   - 목표 / 남은 시간 / 모은 물방울 줄 (기본 카드, 가운데 정렬 3칸 + 세로 구분선, 라벨 11/600 + 값 16/700) — 남은 시간은 지금 영상 길이(1분 이상, 영상마다 다름)에서 줄어드는 "m:ss", 모은 물방울은 "+0" → 1분이 넘으면 "+1" `#3B9AE1` (운동 1번에 1개) 〔D-21〕
   - 차 안 가능 동작: 알약(`#FEF5E7` 배경, `car-outline` + "차 안에서는 주차 중일 때만 해주세요" 13/700 `#B45309`)
   - 안내 상자: "끝까지 하지 않아도 괜찮아요. 움직인 만큼 기록할 수 있어요."
   - 주의사항 12 `textSecondary`
   - 안전 문구 "통증이나 어지러움이 느껴지면 즉시 멈춰주세요" 13/600 `text`
5. 하단 바: [이전 영상] [그만하기] [다음 영상] — 왼쪽·오른쪽 테두리 버튼(`primary`), 가운데 채운 버튼(`success`, `checkmark-circle`). '그만하기'는 실패가 아니라 **마치기**의 의미라 초록을 쓴다
